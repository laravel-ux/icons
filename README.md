# Laravel UX Icons

Laravel UX Icons is a collection of [Lucide](https://lucide.dev/) icons packaged for seamless integration into [Laravel](https://laravel.com/) and [Livewire](https://livewire.laravel.com/) applications.
Designed for modern UI development, these icons work effortlessly with [shadcn/ui](https://ui.shadcn.com/) and [Tailwind CSS](https://tailwindcss.com/).

The bundled upstream Lucide version is recorded in [`LUCIDE_VERSION`](LUCIDE_VERSION).
